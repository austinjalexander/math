# Mathematics lesson structure

Read `docs/agents/PROFILE.md` and the relevant phase map before authoring. Use a numbered `NN-topic-slug/` folder under its phase and preserve existing work.

## Four-file subtopic

- `README.md`: framing, specific prerequisites, observable objectives, file links, study-time estimate, timed exit test, and pass criteria.
- `notes.md`: definitions and hypotheses, derivations, worked examples with explicit checks, common mistakes, connections, references, and the same exit test.
- `problems.md`: about 15 problems spanning drills, conceptual reasoning, applied/structural questions, and one optional stretch. Mark required problems. Repeat the same exit test and time limit.
- `solutions.md`: separate full solutions for every problem and the exit test. End each with **Check.** For a proof, check domain, quantifiers, assumptions, and whether the argument establishes the whole conclusion.

Keep the exit-test heading and statement identical in README, notes, and problems; put its worked answer only in solutions. The normal subtopic test is one new synthesis problem taking under 20 minutes. State critical concepts and actual pass criteria before administering it. Broader assessments may have a different stated duration.

Define symbols before use. Treat examples, counterexamples, and numerical evidence according to what they can establish. Aim for both computational fluency and reasoning; abstract examples can be structural rather than physical. Cite sources without copying textbook passages or wholesale exercises.

Link backward to prerequisites and forward to the next topic, and register the lesson in its phase README. A new lesson does not check progress. For an unspecified large expansion, author one representative module and leave other scopes clearly planned until developed.
