# 6.042J · Mathematics for Computer Science

**Edition:** OCW on Open Learning Library, 2T2019. Use this edition for interactive discrete math alongside the Spring 2015 OCW written reference. MIT recommends single-variable calculus familiarity for the full course. [About](https://openlearninglibrary.mit.edu/courses/course-v1:OCW+6.042J+2T2019/about) · [Course outline](https://openlearninglibrary.mit.edu/courses/course-v1:OCW+6.042J+2T2019/course/) · [Spring 2015 readings](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/pages/readings/)

- **First checkpoint · 25 minutes.** For complexity preparation, open **Unit 1 → 1.5 Quantifiers & Predicate Logic**. Attempt one check, then write and negate a quantified statement of your own. Continue into Problem Set 2 when the relevant work on quantifiers and sets is ready. If proof structure is the immediate gap, start at **1.1–1.2** with Problem Set 1.
- **Later sequence.** Use induction and invariants in Unit 1, congruences and graph structure in Unit 2, counting in Unit 3, then discrete and conditional probability in Unit 4. Reuse these for modular arithmetic, reductions, and bounded error. Keep a relevant exam item unseen for a later benchmark after the corresponding local practice.
