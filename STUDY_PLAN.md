# Study plan

Use [the curriculum](docs/CURRICULUM.md) for scope and [progress](PROGRESS.md) for evidence. Phase numbers organize the library; they are not a requirement to finish all applied subjects before beginning abstract mathematics.

## Choose a route

- **Common foundation:** diagnose 1a/1b, build 1c proof skills, and learn 1e computing as needed. Begin 2a calculus and 2d linear algebra when their own prerequisites are ready; they can run alongside proof study.
- **Engineering route:** 2a → 2b, 2d → 3a; then 3b transforms and 3d numerical methods. Add 2c/2e before 3c PDEs. Use 3e modeling/control after multivariable calculus, linear algebra, ODEs, and numerical basics. Add 4c/4d for uncertainty and fitting.
- **Applied/computational route:** 1e + 2a/2b + 2d → 3d; add 2c → 3e, and 1d + calculus → 4c → 4d. Projects connect algorithms to analytical checks and sensitivity studies.
- **Theoretical/analysis route:** 1c + 2a/2b → 4a; 1b + 2e + 4a → 4b. Add 4c and metric-space topics for 4e, then 6b as appropriate.
- **Abstract route:** 1c + 1d → 5b and 5e; 2d → 5a. Follow groups and proof-based linear algebra into 5c. Build 5d with real-analysis examples, then approach 6a with multivariable/vector calculus and linear algebra.

The arrows summarize part of each route; check the exact topic prerequisites before starting. The advanced paths are optional directions, not a scheduled graduate program. Start 6e projects at any level when their specific prerequisites and acceptance criteria are clear.

## First useful step

No readiness or weekly capacity is recorded. Select a near-term mathematical target and inspect prior work before assigning a long sequence. If integer algebra is ready, [statements and direct proofs](notes/phase-1-foundations/01-statements-direct-proofs/README.md) is available now (4–6 estimated hours over multiple sessions). If not, repair the specific algebra gaps first.

For a calculus/engineering priority, diagnose algebra, functions, trigonometry, and relevant calculus instead of forcing a full introductory proof module before every calculation. A diagnostic routes study; it does not complete a prerequisite topic.

## Workload and session pattern

There is no adopted math-specific weekly allocation. Agree on available time and count reading, video, examples, problem solving, coding, corrections, assessment, and reflection inside that capacity. Coordinate with physics and quantum work; reused work counts once.

A possible 60-minute practice session is 10 minutes of retrieval, 15 of reading/derivation, 25 of problems, and 10 of corrections/logging. Adapt to the actual session; schedule an unaided exit assessment separately. These are planning estimates, never records of elapsed work.

Maintain one main topic and, when useful, one supporting proof/computation strand. Check [external-course return items](EXTERNAL_COURSES.md) at topic transitions. Review dates are recorded only when agreed; this plan creates no recurring reminders.
