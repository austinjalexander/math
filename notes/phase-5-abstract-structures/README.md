# Phase 5: Abstract algebra, topology, and number theory

[Curriculum](../../docs/CURRICULUM.md) · [Study plan](../../STUDY_PLAN.md) · [Progress](../../PROGRESS.md)

These are planned topic scopes. A topic entry is not a complete lesson or an assessed learner result. Author subtopics when they become current; use prerequisites rather than requiring every earlier phase.

## 5a Proof-based linear algebra

**Prerequisites:** 1c, 2d

Prove results about vector spaces, quotient/dual spaces, linear operators, canonical forms, and spectral structure over stated fields.

**Lesson status:** planned; no full problem set or exit assessment authored.

## 5b Groups and symmetry

**Prerequisites:** 1c, 1d; 2d for matrix examples.

Work with groups, subgroups, homomorphisms, quotient groups, group actions, and structure theorems with explicit hypotheses.

**Lesson status:** planned; no full problem set or exit assessment authored.

## 5c Rings, fields, and Galois theory

**Prerequisites:** 5b; 5a for extension degree.

Use ideals, quotient rings, polynomial arithmetic, field extensions, and the connection between automorphisms and solvability.

**Lesson status:** planned; no full problem set or exit assessment authored.

## 5d Topology and metric spaces

**Prerequisites:** 1c; 4a for metric-space examples.

Prove results about open/closed sets, continuity, compactness, connectedness, products, and quotient constructions.

**Lesson status:** planned; no full problem set or exit assessment authored.

## 5e Number theory

**Prerequisites:** 1c, 1d; 5b/5c for algebraic extensions.

Prove divisibility/congruence results; use Euclidean algorithms, modular arithmetic, Diophantine equations, and elementary prime arguments.

**Lesson status:** planned; no full problem set or exit assessment authored.
