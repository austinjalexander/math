# Phase 6: Advanced connections and independent work

[Curriculum](../../docs/CURRICULUM.md) · [Study plan](../../STUDY_PLAN.md) · [Progress](../../PROGRESS.md)

These are planned topic scopes. A topic entry is not a complete lesson or an assessed learner result. Author subtopics when they become current; use prerequisites rather than requiring every earlier phase.

## 6a Differential geometry and manifolds

**Prerequisites:** 2e, 4a, 5a, 5d

Use charts, tangent spaces, differential forms, metrics, and curvature; connect intrinsic and coordinate descriptions.

**Lesson status:** planned; no full problem set or exit assessment authored.

## 6b Functional and harmonic analysis

**Prerequisites:** 3b, 4e, 5a, 5d

Study normed/Hilbert spaces, bounded operators, convergence, and Fourier methods beyond finite dimensions.

**Lesson status:** planned; no full problem set or exit assessment authored.

## 6c Variational methods and dynamical systems

**Prerequisites:** 3a, 3e, 4a; 6b for infinite-dimensional extensions.

Derive Euler-Lagrange equations, analyze phase portraits/bifurcations, and compare analytical and numerical stability.

**Lesson status:** planned; no full problem set or exit assessment authored.

## 6d Algorithms, information, and mathematical computation

**Prerequisites:** 1d, 1e, 2d, 4c; 5b/5c for algebraic algorithms.

Analyze complexity, graph algorithms, information measures, and algebraic/numerical algorithms; introduce formal verification when useful.

**Lesson status:** planned; no full problem set or exit assessment authored.

## 6e Independent mathematical projects

**Prerequisites:** Prerequisites selected per question; scope and acceptance criteria agreed before work.

Formulate a question, trace sources, prove or compute a result, validate it independently, and write limitations and reproducible evidence.

**Lesson status:** planned; no full problem set or exit assessment authored.
