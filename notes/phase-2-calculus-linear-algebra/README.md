# Phase 2: Calculus and linear algebra

[Curriculum](../../docs/CURRICULUM.md) · [Study plan](../../STUDY_PLAN.md) · [Progress](../../PROGRESS.md)

These are planned topic scopes. A topic entry is not a complete lesson or an assessed learner result. Author subtopics when they become current; use prerequisites rather than requiring every earlier phase.

## 2a Single-variable differential calculus

**Prerequisites:** 1a, 1b

Use limits, continuity, derivative definitions/rules, approximation, and constrained word problems; state theorem hypotheses.

**Lesson status:** planned; no full problem set or exit assessment authored.

## 2b Integration, sequences, and series

**Prerequisites:** 2a

Apply the fundamental theorem, integration methods, improper integrals, convergence tests, and Taylor approximations with error bounds.

**Lesson status:** planned; no full problem set or exit assessment authored.

## 2c Multivariable calculus

**Prerequisites:** 2a, 2b; vectors/matrices from 2d.

Compute partial derivatives, Jacobians, Hessians, constrained extrema, multiple integrals, and changes of variables.

**Lesson status:** planned; no full problem set or exit assessment authored.

## 2d Linear algebra

**Prerequisites:** 1a, 1b; 1c for proofs. Calculus is not required to start.

Solve linear systems; explain subspaces, bases, rank, linear maps, eigenvalues, inner products, least squares, and SVD.

**Lesson status:** planned; no full problem set or exit assessment authored.

## 2e Vector calculus

**Prerequisites:** 2c, 2d

Evaluate line/surface integrals, gradient/divergence/curl, and apply Green, Stokes, and divergence theorems with their hypotheses.

**Lesson status:** planned; no full problem set or exit assessment authored.
