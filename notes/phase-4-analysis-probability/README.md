# Phase 4: Analysis, probability, and statistics

[Curriculum](../../docs/CURRICULUM.md) · [Study plan](../../STUDY_PLAN.md) · [Progress](../../PROGRESS.md)

These are planned topic scopes. A topic entry is not a complete lesson or an assessed learner result. Author subtopics when they become current; use prerequisites rather than requiring every earlier phase.

## 4a Real analysis

**Prerequisites:** 1c, 2b

Prove results on completeness, sequences, limits, continuity, differentiation, integration, and uniform convergence.

**Lesson status:** planned; no full problem set or exit assessment authored.

## 4b Complex analysis

**Prerequisites:** 1b, 2e, 4a

Analyze holomorphic functions, Cauchy-Riemann equations, contour integrals, power/Laurent series, and residues.

**Lesson status:** planned; no full problem set or exit assessment authored.

## 4c Probability

**Prerequisites:** 1d, 2b; 2c for multivariate densities.

Define sample spaces and random variables; use conditional probability, independence, distributions, expectation, and limit theorems.

**Lesson status:** planned; no full problem set or exit assessment authored.

## 4d Statistics and inference

**Prerequisites:** 2d, 4c; 1e for simulation.

Estimate parameters, construct intervals, test hypotheses, fit regression models, and assess assumptions and uncertainty.

**Lesson status:** planned; no full problem set or exit assessment authored.

## 4e Measure, integration, and stochastic processes

**Prerequisites:** 4a, 4c; metric-space material from 5d as needed.

Use sigma-algebras, measures, Lebesgue integration, convergence theorems, conditional expectation, and introductory Markov processes.

**Lesson status:** planned; no full problem set or exit assessment authored.
