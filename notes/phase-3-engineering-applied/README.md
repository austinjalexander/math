# Phase 3: Engineering and applied mathematics

## 3a Ordinary differential equations and systems

**Prerequisites:** 2b, 2d; partial derivatives from 2c for nonlinear systems.

Solve first/second-order equations and linear systems; interpret initial conditions, equilibria, stability, and numerical trajectories.

**Lesson status:** planned; no full problem set or exit assessment authored.

## 3b Fourier, Laplace, and signal methods

**Prerequisites:** 1b, 2b, 3a

Compute transforms, Fourier series, convolution, frequency response, sampling examples, and linear-system solutions with stated conventions.

**Lesson status:** planned; no full problem set or exit assessment authored.

## 3c Partial differential equations and boundary problems

**Prerequisites:** 2e, 3a, 3b

Formulate heat, wave, and Laplace problems; use separation of variables and check boundary/initial conditions.

**Lesson status:** planned; no full problem set or exit assessment authored.

## 3d Numerical analysis and scientific computing

**Prerequisites:** 1e, 2b, 2d; 3a for ODE solvers.

Analyze floating-point error, conditioning, root finding, interpolation, quadrature, linear solves, and ODE convergence.

**Lesson status:** planned; no full problem set or exit assessment authored.

## 3e Optimization, modeling, and control

**Prerequisites:** 2c, 2d, 3a, 3d; 4c/4d for inference-based models.

Formulate objectives/constraints, use gradients and convexity, fit models, analyze feedback/stability, and test sensitivity.

**Lesson status:** planned; no full problem set or exit assessment authored.
