# Mathematical projects

Projects connect proof, modeling, and computation. No project is adopted or completed yet. Start from [the project template](../templates/project-template.md), state prerequisites and acceptance criteria, and link actual evidence to [progress](../PROGRESS.md).

Possible directions, selected only when their prerequisites are ready:

- Compare analytical and numerical solutions of a damped oscillator; quantify time-step error and sensitivity (**3a/3d**).
- Derive least squares, fit a calibration model, and assess residuals/uncertainty on clearly labeled synthetic or measured data (**2d/4d**).
- Compare Fourier representations of a signal and inspect truncation/sampling effects (**3b**).
- Classify symmetries of a regular polygon using group actions and a complete argument (**5b**).
- Prove a convergence result and compare it with a finite numerical exploration (**4a/3d**).

These are proposals. Source data, experiments, performance, and mathematical results require their own evidence. A project can contribute assessed work to a topic; it does not complete the whole curriculum.
