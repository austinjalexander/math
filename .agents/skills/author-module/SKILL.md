# Author a curriculum module

Read `AGENTS.md`, `docs/agents/PROFILE.md`, `docs/agents/module-structure.md`, and `docs/agents/math-and-code-style.md`. Read all four files in the profile's reference module, the relevant curriculum/study-plan sections, selected resources, and parent course README.

1. Locate the correct course/phase and create `NN-topic-slug/` following its existing names. Preserve existing drafts and learner work.
2. Draft `README.md`: framing, prerequisites, concrete verb-first objectives, file links, study-time estimate, and an achievable unaided exit test with a time limit.
3. Write `notes.md`: concepts and derivations, worked examples with checks, common mistakes, prerequisite/forward links, exit test, and references.
4. Write roughly 15 problems with drill, conceptual, applied, and one optional stretch; explicitly identify the required set. Repeat the same exit test/time limit.
5. Work every problem and the exit test in `solutions.md`, with **Check.** lines. Independently verify calculations; keep answers out of learner-only assessment files.
6. Link the module from its parent README. Confirm alignment with the curriculum, correct references and local links, identical assessment statements, and a manageable time budget.

Use the shared structure for exact counts/style and the profile for scientific/code conventions. Follow the user's requested authoring scope; use one representative module for feedback before an unspecified large expansion. Never check learner progress because material was generated, and do not copy long textbook passages.
