# Diagnose prerequisite readiness

Read `AGENTS.md`, `docs/agents/PROFILE.md`, `docs/agents/tutoring.md`, `PROGRESS.md`, and the target module/course README. Recent completed prerequisite exit evidence can satisfy readiness without another quiz.

1. Identify unchecked or unsupported prerequisites. If the profile names an entry diagnostic suitable for this request, use its existing questions and rubric rather than creating a competing assessment.
2. Otherwise choose 5–7 questions: 2–3 drill, 2–3 applied, and up to one synthesis. Assign realistic 3–10 minute limits per question. Define the rubric/critical concepts before running it. Save `diagnostic.md` in the target module/course folder; keep solutions separate.
3. Present one problem at a time for an interactive diagnostic. For a prewritten assessment, follow its delivery instructions. Keep worked answers closed and give no hints during unaided work. Ask the learner to report elapsed time and assistance; record unknown timing honestly.
4. Grade completed work with `grade-solution`. For a new diagnostic: proceed at >=80% with clean reasoning, within time, and no critical prerequisite gap; target a refresh at 50–<80% or a specific slow/weak prerequisite; return to the prerequisite module below 50% or with fundamental confusion. The existing assessment's rubric takes precedence.
5. Name one next path, the precise gaps, repair resources, and a changed-number retest. Save actual readiness evidence and gaps in the profile's log and the tracker repair section. **Do not check prerequisite module completion from this short diagnostic.** Completion requires the full shared mastery gate.

Readiness is a routing decision. Do not label an assisted or untimed attempt an unaided timed pass, or infer mastery from self-report. Explain assessment criteria without exposing the answer key before the attempt.
