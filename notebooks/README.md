Keep future subject notebooks beside their module when they depend on its lesson. Use this directory for cross-topic examples. Run current notebooks from a fresh kernel in the `uv` environment. State domains, dimensions, assumptions, randomness/seeds, tolerances, and exact versus approximate claims. Keep large outputs out of commits and save intentional figures next to the work.
